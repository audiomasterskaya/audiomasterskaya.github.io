# 🎵 АудиоМастерская

**Онлайн-аудиоредактор в браузере: триммер, склейщик, мультифрагментный монтаж.**

Работает **полностью в браузере**. Файлы **не отправляются на сервер** — всё
декодирование, обработка и экспорт происходят у вас на устройстве. Никаких
загрузок, регистраций и подписок.

---


### 🎵 ИСХОДНИК (окно редактирования файла)

- Загрузка аудио **перетаскиванием** файла в окно, через **диалог выбора** или
  по **правой кнопке мыши** на волне.
- Волна с плавным плейхедом и счётчиком времени.
- Метки **ВХОД** и **ВЫХОД** — ставятся кнопками или горячими клавишами
  `I` и `O`. Обе метки можно двигать мышью за «шарики».
- Воспроизведение: от начала файла, от точки ВХОД или выделенного диапазона.
- Точная перемотка: `←`/`→` — по 0.1 с, с `Shift` — по 0.01 с; при
  воспроизведении шаг 5 с и 0.1 с соответственно.
- **Перетаскивание выделения в МАСТЕР** прямо мышью (с подсветкой целевой
  панели и ghost-иконкой «⬇ В Мастер»).

### 🎬 МАСТЕР (окно монтажа)

- Мультифрагментный монтаж: неограниченное число фрагментов, каждый — со
  своей обрезкой, громкостью и краевыми фейдами.
- **Смена порядка фрагментов** перетаскиванием.
- **Обрезка фрагмента** перетаскиванием ручек по краям.
- **Кроссфейды между соседними фрагментами** — включите галочку 🔀 МИКС и
  тяните оранжевые зоны по краям фрагментов.
- **Регулировка громкости каждого фрагмента** розовой линией — в том числе
  «на лету» во время воспроизведения.
- **Разрез фрагмента по плейхеду** — клавиша `C`.
- **Копирование / вставка / дублирование** фрагментов — `Ctrl+C`, `Ctrl+V`,
  `Ctrl+D`, `Ctrl+X`, `Ctrl+A`.
- **Undo / Redo** — до 50 шагов истории (`Ctrl+Z` / `Ctrl+Y`).
- **Цикл воспроизведения** — галочка 🔁 ЦИКЛ.
- Плейхед свободно перемещается по линейке мышью, в т.ч. во время
  воспроизведения.

### 💾 Экспорт

- **WAV** — без потерь, PCM 16 bit.
- **MP3** — через [`lamejs`](https://github.com/zhuker/lamejs), битрейт
  на выбор: 128 / 192 / 320 kbps.
- **Нормализация громкости** — peak → -0.3 dB.
- **Fade по краям микса** — 50 мс на входе и выходе, включается/выключается.
